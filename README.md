# QCA Combinational Circuits

## 🔍 Overview

This project focuses on the design and analysis of combinational logic circuits using **Quantum-dot Cellular Automata (QCA)**, an emerging nanoscale technology that overcomes the limitations of traditional CMOS systems.

The work demonstrates efficient circuit design with reduced cell count, compact area, and low energy dissipation.

---

## ⚙️ Circuits Implemented

* 4-to-2 Encoder
* 2-bit Binary to Gray Code Converter
* 3-bit Binary to Gray Code Converter



## ⚡ Key Highlights

* Significant reduction in cell count
* Compact nanoscale circuit design
* Low energy dissipation
* Efficient signal propagation using QCA clocking
